How Veyro works.

Licenses, accounts, the backend, and the desktop app — everything in one place.

1 · The stack

Veyro is two products sharing one backend:

  • Veyro desktop app — Windows suite: diagnostics, optimization with real System Restore points, performance monitoring, upgrade advisor, driver check, system report.
  • This website — accounts, license management and (for the admin) the key generator.
  • The backend — a real HTTP API + database on port 9175. It is started automatically inside the app and can also run standalone with node server/server.js.

2 · Key format

Every key looks like this and is validated twice — a lightweight local check in the app, and the authoritative check on the server:

VEYR0-XXXXX-XXXXX-XXXXX
  • The expiry timestamp is encoded inside the key itself.
  • A checksum character protects the key from typos and tampering.
  • All-zero expiry means LIFETIME.

3 · Durations

  • 3 Hours · 24 Hours · 3 Days · 1 Week · 1 Month · 1 Year · Lifetime

Expiry is computed by the server at generation time and checked at every activation. The app trusts the same source of truth — there is no client-side "trust me" path.

4 · Accounts

  • Register an account — the first account ever created becomes the administrator.
  • Passwords are hashed with scrypt and never stored in plain text.
  • Login issues a bearer token; sessions expire after 30 days of inactivity.

5 · Activation rules

  • A key is activated on the server and bound to the first account that uses it.
  • The same key on another account is rejected with IN_USE.
  • Revoked keys stop working immediately — even on a PC that already activated them.
  • Expired keys are rejected server-side; the expiry timestamp is never taken from the client.

6 · Admin

  • Generate keys for any of the 7 durations, in batches of up to 20.
  • Search, filter, revoke and un-revoke keys.
  • See every account, its keys and promote/demote admin rights.

7 · Running it

  • The desktop app starts the backend on boot. Nothing to configure.
  • Standalone: node server/server.js → http://127.0.0.1:9175.
  • Database lives in server/db.json (or %APPDATA%\VEYRO\server-db.json inside the packaged app). Keep a backup if you move machines.
This is a local-first product: the API binds to 127.0.0.1. To expose it publicly, deploy server/server.js on a host and open the port — the site and the app talk to whatever origin they are configured with.

8 · Quick start

  1. Open the app (veyro://optcenter) or this site.
  2. Register — you are the admin on a fresh backend.
  3. On Admin, generate a key.
  4. Paste it on the Dashboard or in App → Settings → Premium.
  5. Same status in both places. Expiry, revocation and checksums are enforced by the server.
